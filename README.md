🏗️ Construction Website

A modern and responsive **Construction Website** built using **HTML, CSS, and JavaScript**.
The website is designed to present construction services, company information, projects, and contact details in a clean and professional layout.

 🌐 Live Demo

👉 [View Live Website](https://palakchhajed19.github.io/Construction-Website/)

 📌 Features

* 🏠 Attractive and responsive homepage
* 🏗️ Construction services section
* 📋 About/Company information
* 🏢 Projects/Portfolio section
* 📞 Contact section
* 📱 Responsive design for different screen sizes
* 🎨 Clean and modern user interface
* ⚡ Interactive elements using JavaScript
* 🌐 Deployed using GitHub Pages

 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout and responsive design
* **JavaScript** – Interactivity and dynamic functionality
* **Git & GitHub** – Version control and project hosting
* **GitHub Pages** – Website deployment

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/PalakChhajed19/Construction-Website.git
```

### 2. Open the project

Open the project folder in **Visual Studio Code**.

### 3. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
